# InstaSessions

A native Android app built with Jetpack Compose and multi-profile AndroidX WebView that lets you run multiple isolated Instagram sessions simultaneously, each with its own custom device identity and User-Agent.

## Features
- **Isolated Multi-Sessions:** Each session uses its own isolated WebView profile and cookie store.
- **Background Keep-Alive (`▶` / `⏸`):** Choose which sessions stay running and "Active now" in the background.
- **1,600+ Device Presets:** Searchable presets across iPhone (including iPhone Duo & iPhone 18 series), iPad, Android Foldables, Android flagships, Windows, macOS, and Linux, plus custom User-Agent creation.
- **Draggable Auto-Fading Floating Button:** Quickly switch between sessions from anywhere on screen.
- **Full Media Upload Support:** Upload Posts, Stories, Reels, and Profile Pictures directly from your device gallery.
